# ari-legal

Canonical legal documents for the **Ari** Telegram bot operated by
**JoCoding Inc.**

| Document | Purpose |
|---|---|
| [`privacy-policy.ko.md`](./privacy-policy.ko.md) | 개인정보 처리방침 (PIPA Art. 30) |
| [`terms.ko.md`](./terms.ko.md) | 이용약관 (서비스 이용약관) |
| [`CHANGELOG.md`](./CHANGELOG.md) | Per-version change log |

These files are linked from the bot's `/start` consent prompt via
Telegram URL buttons. The bot tracks each user's accepted version and
re-prompts when either document bumps to a new version.
